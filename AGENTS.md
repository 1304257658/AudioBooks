# Repository Instructions

Before doing any work in this repository, read and follow `docs/governance/codex-operating-rules.md`.

- Store all human-facing Markdown documentation under `docs/`.
- This root `AGENTS.md` is the sole Markdown exception because Codex requires a repository-level instruction entry point.
- On `codex/audit`, synchronize the remote audit branch and latest product baseline before every audit, then keep all audit work documentation-only.
- Commit verified functional changes without asking again. Push low-risk changes directly; important changes require explicit approval before push.
- Audit-branch documentation and evidence may be committed and pushed directly after verification.
